# Документация REST API: Asana Task & Resource Management (v1)

* **Базовый URL API:** `http://localhost:3000/api/v1`
* **Интерактивная документация (Swagger UI):** `http://localhost:3000/api/docs`
* **Формат данных:** `application/json`

## 1. Ресурс: Проекты (`/api/v1/projects`)

### 1.1. Получение списка проектов
* **Запрос:** `GET /api/v1/projects`
* **Query-параметры:**
  * `search` (string, опционально) — поиск по наименованию и описанию.
  * `sortBy` (string, опционально) — поле сортировки (`name`, `createdAt`).
  * `order` (string, опционально) — направление (`asc` или `desc`).
* **Ответ `200 OK`:**
```json
{
  "success": true,
  "count": 1,
  "data": [
    {
      "id": 1,
      "name": "Разработка корпоративного портала",
      "description": "Создание внутренней системы управления ресурсами",
      "color": "#4f46e5",
      "deadline": "2026-12-31T23:59:59.000Z",
      "createdAt": "2026-01-10T08:00:00.000Z"
    }
  ]
}
```

### 1.2. Получение проекта по ID
* **Запрос:** `GET /api/v1/projects/1`
* **Ответ `200 OK`:** объект проекта.
* **Ошибка `404 Not Found`:**
```json
{
  "success": false,
  "error": "Проект с ID 999 не найден."
}
```

### 1.3. Получение задач конкретного проекта (Вложенный ресурс)
* **Запрос:** `GET /api/v1/projects/1/tasks`
* **Ответ `200 OK`:**
```json
{
  "success": true,
  "count": 2,
  "data": [
    {
      "id": 1,
      "title": "Спроектировать реляционную модель базы данных",
      "status": "done",
      "priority": "high",
      "estimatedHours": 12,
      "projectId": 1
    }
  ]
}
```

### 1.4. Создание проекта
* **Запрос:** `POST /api/v1/projects`
* **Тело запроса (JSON):**
```json
{
  "name": "Мобильное приложение",
  "description": "Клиент на React Native",
  "color": "#10b981",
  "deadline": "2026-11-15T18:00:00.000Z"
}
```
* **Ответ `201 Created`:**
```json
{
  "success": true,
  "message": "Проект успешно создан.",
  "data": {
    "id": 4,
    "name": "Мобильное приложение",
    "description": "Клиент на React Native",
    "color": "#10b981",
    "deadline": "2026-11-15T18:00:00.000Z",
    "createdAt": "2026-10-29T14:30:00.000Z"
  }
}
```
* **Ошибка `400 Bad Request`:**
```json
{
  "success": false,
  "error": "Поле \"name\" обязательно к заполнению."
}
```

### 1.5. Частичное обновление проекта (PATCH)
* **Запрос:** `PATCH /api/v1/projects/1`
* **Тело запроса:** `{"color": "#ef4444"}`
* **Ответ `200 OK`:** обновленный объект проекта.

### 1.6. Удаление проекта
* **Запрос:** `DELETE /api/v1/projects/1`
* **Ответ `200 OK`:**
```json
{
  "success": true,
  "message": "Проект «Разработка корпоративного портала» успешно удален."
}
```

## 2. Ресурс: Задачи (`/api/v1/tasks`)

### 2.1. Получение списка задач с фильтрацией
* **Запрос:** `GET /api/v1/tasks?status=in_progress&priority=urgent`
* **Query-параметры:**
  * `status` (`backlog`, `in_progress`, `review`, `done`)
  * `priority` (`low`, `medium`, `high`, `urgent`)
  * `projectId` (число)
  * `assigneeId` (число)
  * `search` (поиск подстроки)
* **Ответ `200 OK`:** массив отфильтрованных задач.

### 2.2. Создание задачи (с валидацией верхних границ)
* **Запрос:** `POST /api/v1/tasks`
* **Тело запроса (JSON):**
```json
{
  "title": "Настроить CI/CD",
  "description": "Автоматизировать деплой на тестовый контур",
  "status": "in_progress",
  "priority": "urgent",
  "estimatedHours": 8,
  "projectId": 1,
  "assigneeId": 2
}
```
* **Ответ `201 Created`:**
```json
{
  "success": true,
  "message": "Задача успешно создана.",
  "data": {
    "id": 4,
    "title": "Настроить CI/CD",
    "estimatedHours": 8,
    "createdAt": "2026-10-29T14:35:00.000Z"
  }
}
```
* **Ошибка `400 Bad Request` (Превышение лимита):**
```json
{
  "success": false,
  "error": "Оценка времени должна быть в диапазоне от 0 до 666 часов."
}
```

### 2.3. Частичное обновление задачи (PATCH)
* **Запрос:** `PATCH /api/v1/tasks/1`
* **Тело запроса:** `{"status": "done"}`
* **Ответ `200 OK`:** обновленная задача с актуализированным `updatedAt`.

### 2.4. Удаление задачи
* **Запрос:** `DELETE /api/v1/tasks/1`
* **Ответ `200 OK`:** подтверждение удаления с телом удаленной задачи.

## 3. Ресурс: Участники команды (`/api/v1/users`)

### 3.1. Получение участников команды
* **Запрос:** `GET /api/v1/users?role=developer`
* **Ответ `200 OK`:** массив участников.

### 3.2. Добавление участника
* **Запрос:** `POST /api/v1/users`
* **Тело запроса:**
```json
{
  "name": "Сергей Васильев",
  "email": "sergey.vasiliev@asana.team",
  "role": "developer"
}
```
* **Ответ `201 Created`:** объект созданного пользователя.
* **Ошибка `409 Conflict` (дубликат email):**
```json
{
  "success": false,
  "error": "Пользователь с таким email уже существует."
}
```

### 3.3. Удаление участника
* **Запрос:** `DELETE /api/v1/users/2`
* **Ответ `200 OK`:** подтверждение удаления пользователя.
```
